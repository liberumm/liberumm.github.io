01 · 作戦概要

周回衛星 LUNA-X の地表は 1周12,000ユニット。ステージごとのシードで地形・施設・敵編成が変化し、6つの設定ステージ以降は無限に生成します。左右に飛び続けると同じ地形へ戻ります。地上の民間人を鹵獲する敵を止め、落下する人を回収して着陸してください。科学ステージの物理係数と、空想ステージの異常物理を区別して設定しています。

衛星ミニマップ：白 = 自機 / 赤 = 敵 / 橙 = 鹵獲機 / 紫 = ボス / 緑 = 救助者。ラインレーザーは敵弾を貫通し、命中した敵ごとに火花・HIT表示が出ます。波動砲は通常敵弾を飲み込み消滅しません。軽量弾は相殺します。

緊急装備：B 範囲ボム / R 近接ブレード / F ワープ。Qで搭載武器を切り替え、画面アイコンも使用できます。波動砲は押し続けて充填し、離すまで最大状態を維持します。マウス追従は初期OFF、M/🖱ボタンでONにできます。
